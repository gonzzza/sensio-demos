# Sensio Partners demos

Small, runnable examples of the integration and automation work
[Sensio Partners](https://sensiopartners.com) does for growing SaaS companies. Each one shows how a
production integration behaves when things go wrong, not just when they go right.

| Demo | What it shows |
|---|---|
| [Billing → CRM sync](crm-sync) | Syncing customers between systems with retries, rate-limit handling, a dead-letter queue, a circuit breaker, and alerts. |
| Customer onboarding workflow | Coming soon. |

Each demo runs locally with one command and uses only fictional data.
